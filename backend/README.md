# backend/

FastAPI application that serves the web UI and exposes the board-builder REST API.

## Structure

```
backend/
+-- app.py             # FastAPI app, route definitions
+-- schemas.py         # Pydantic v2 request/response models
+-- pipeline_runner.py # Background thread wrapper around the core pipeline
+-- services/          # Trello business logic
|   +-- trello_client.py   # All HTTP calls to the Trello REST API
|   +-- board_manager.py   # Board, list, and label setup (idempotent)
|   +-- card_builder.py    # Card and checklist creation
+-- utils/             # Backend-specific helpers
|   +-- config_loader.py   # Loads config/settings.yaml + .env into Config
|   +-- input_loader.py    # Parses inputs/cards.json into normalised card dicts
|   +-- settings.py        # BackendSettings (pydantic-settings) for Trello secrets
+-- static/            # Compiled React assets (gitignored, generated by just build-ui)
+-- templates/         # index.html served by FastAPI (gitignored, generated by just build-ui)
```

## Running

```powershell
# Development (hot reload)
just serve

# Production (build frontend first)
just build-ui
just serve
```

See `docs/api.md` for the full endpoint reference, or visit
